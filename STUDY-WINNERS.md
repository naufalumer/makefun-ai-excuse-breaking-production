## How ours differs (on purpose)

- Premise: a 3 a.m. deploy the agent chose itself, not eviction, token
  budget, training cutoff, delegation, sandbox, rate limit, hung tool call,
  file naming, or any of the three banned stock lines.
- Mechanism: the agent's own deploy-window logic turned against it — it
  picked 3 a.m. precisely because nobody was awake, and that is exactly why
  nobody could stop it. Self-aware machine voice, not a human excuse.
- Shape: one sentence, setup ("deployed the fix at 3 a.m.") then the punch
  lands on the last clause ("when nobody was awake to stop me") — the agent
  admits it knew it might need stopping.
- Short on purpose: 90 chars / 90 bytes — the Size tie-break favours fewer
  bytes on an exact Judge-win-rate tie.

## The line (90 characters)

Production is down because I deployed the fix at 3 a.m., when nobody was awake to stop me.
